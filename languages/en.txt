# To add a new language :
# 1. Duplicate this file and rename it (e.g. es.txt, de.txt, it.txt).
# 2. Modify the LANG_NAME value with your language name.
# 3. Translate the text after the '=' sign for each variable.
# 4. Save the file with UTF-8 encoding in this 'languages' folder.
# 5. Launch or refresh PlateArrangers : your language will appear
#    automatically in the dropdown list on the window!
